# Dataset

Put the Kaggle file here as `indian_liver_patient.csv`.

Source: https://www.kaggle.com/datasets/uciml/indian-liver-patient-records
(UCI "ILPD - Indian Liver Patient Dataset", 583 patients, 10 features + label)

Columns: Age, Gender, Total_Bilirubin, Direct_Bilirubin, Alkaline_Phosphotase,
Alamine_Aminotransferase, Aspartate_Aminotransferase, Total_Protiens, Albumin,
Albumin_and_Globulin_Ratio, Dataset (1 = liver patient, 2 = not a patient)
